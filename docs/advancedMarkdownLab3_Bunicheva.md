## Сноска
Markdown активно применяется в современной веб-разработке и составлении документации к API[^markdown].

[^markdown]: Синтаксис Markdown поддерживается GitHub, GitLab и большинством редакторов текста и кода.

## Alert-блок
> [!IMPORTANT]
> При работе с Git всегда проверяйте статус файлов через `git status` перед тем, как делать коммит!

## Escape-символы (Экранирование)
Если необходимо вывести символ, который Markdown воспринимает как
управляющий:
\# Это не заголовок
\*это просто звёздочка\*

## HTML-тег с атрибутом
<p style="background-color: #f0f9ff; padding: 12px; border-radius: 6px; border: 1px solid #bae6fd;">
Данный параграф стилизован с помощью <strong>HTML-тега</strong> внутри Markdown документа.
</p>
